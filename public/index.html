EduPage Architecture & API Specification for nampm.edupage.org

Comprehensive reverse-engineering guide of the proprietary RPC protocol and database schema used by aSc EduPage for the Presidential School in Namangan (nampm.edupage.org).

1. RPC Protocol & Payload Structure

EduPage executes actions through HTTP POST requests to service modules where the function name is declared via the __func query parameter. The JSON request body wraps function arguments into an array: 

POST https://nampm.edupage.org/{module_path}?__func={functionName}
Content-Type: application/json; charset=utf-8
Referer: https://nampm.edupage.org/timetable/

{
  "__args": [null, ...parameters],
  "__gsh": "00000000",
  "__client_redirect": null
}

The first element of __args is always null (context placeholder). __gsh represents the guest security hash ("00000000" for anonymous public read queries). Responses are wrapped in {"r": ...}.
