EduPage Architecture & API Specification for nampm.edupage.org

Proprietary RPC protocol and database schema used by aSc EduPage for the Presidential School in Namangan (nampm.edupage.org).

1. RPC Protocol & Payload Structure

EduPage executes actions through HTTP POST requests to service modules where the function name is declared via the __func query parameter: 

POST https://nampm.edupage.org/{module_path}?__func={functionName}
Content-Type: application/json; charset=utf-8
Referer: https://nampm.edupage.org/timetable/

{
  "__args": [null, ...parameters],
  "__gsh": "00000000",
  "__client_redirect": null
}

The first element of __args is always null. __gsh is the guest security hash ("00000000" for anonymous public read queries). Responses are wrapped in {"r": ...}.

2. Discovered Public Endpoints

POST getTTViewerData

Discovers published terms, years, and active timetable ID.

POST regularttGetData

Returns the full relational database: classes, teachers, subjects, rooms, lessons, cards.

POST getSubstViewerDayDataHtml

Retrieves daily teacher substitution duties and class room adjustments.

POST curentttGetData

Retrieves dynamic daily cards for any class and date.
